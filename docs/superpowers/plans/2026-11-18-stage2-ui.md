# Stage 2B: attention board, card console and artifacts in the UI — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the Mission board into the attention cockpit: cards sorted by what needs the Captain, a card console that shows the log timeline and artifacts with open actions, and the artifact/PR display — all in TypeScript against the `Backend` contract.

**Architecture:** Pure display logic goes in new small modules (`src/attention.ts`, `src/artifacts.ts`) that are unit-tested with vitest; components stay thin and read from `BoardView`. `src/api.ts` and `src/mock.ts` grow the four Stage 2A commands so `npm run dev` in a plain browser keeps working as the demo. No Rust changes.

**Tech Stack:** React 18 + TypeScript, Vite, Vitest. No new npm dependencies.

**Spec:** `docs/superpowers/specs/2026-11-17-starfleet-bridge-design.md` (§6 artifacts and open actions, §7 the attention board, §8.2 derived card state, §9 MVP vs deferred)

**Depends on:** Stage 2A (`docs/superpowers/plans/2026-11-18-stage2-core.md`) for the Tauri commands it calls — `add_artifact`, `open_artifact`, `read_log`, `append_log`. The two plans share no files and can run in parallel worktrees; this plan is fully testable against the mock backend without 2A merged.

## Global Constraints

- No new npm dependencies.
- Every function component in `src/` is `.tsx`; pure helpers are `.ts` with a matching test in `src/__tests__/`.
- Card state values are exactly the core's: `empty blocked working idle done paused interrupted offline` (`src/api.ts:14`).
- The board keeps showing done cards behind the existing toggle (`Board.tsx:132-145`).
- `npx tsc --noEmit` and `npm test` must pass.

## Shared contract with Stage 2A

```ts
addArtifact(cardId: string, kind: ArtifactKind, label: string, target: string): Promise<string>;
openArtifact(cardId: string, artifactId: string): Promise<void>;
readLog(cardId: string, limit?: number): Promise<LogEntry[]>;
appendLog(cardId: string, text: string, opts?: { kind?: string; sessionId?: string | null }): Promise<LogEntry>;
```

```ts
export interface LogEntry {
  id: string;
  owner: string;            // "captain" or an agent id
  at: number;
  kind: string;             // "note" | "decision" | "prompt" | "result" | "artifact"
  text: string;
  links: string[];
  session_id: string | null;
}
```

Tauri commands and their argument names: `add_artifact(card_id, kind, label, target)`, `open_artifact(card_id, artifact_id)`, `read_log(card_id, limit)`, `append_log(card_id, text, kind, session_id)`.

## Review Focus

1. A card whose newest session is `interrupted` while an older session is `blocked` — the board must still show it at the top (blocked aggregates, spec §8.2). Pinned in Task 1.
2. A PR artifact with no status yet (`last_status: null`) versus one checked long ago — the first reads "checking…", the second shows its age, so a stale green is never mistaken for fresh. Pinned in Task 4.
3. A card with 500 log entries — the console must not render them all and stall. Pinned in Task 5.
4. An `open_artifact` that fails (no `xdg-open`, PR url deleted) — the console shows the error and stays usable. Pinned in Task 6.
5. A done card's artifacts and logs — they stay readable after the card is marked done. Pinned in Task 5.

### Task 1: Attention ordering as a pure function

**Files:**
- Create: `src/attention.ts`
- Test: `src/__tests__/attention.test.ts`
- Modify: `src/components/Board.tsx:114-116` (use it instead of the inline filter)

**Interfaces:**
- Consumes: `Card`, `CardState` from `../api` (`api.ts:57,14`).
- Produces: `export function attentionRank(c: Card): number` — lower is more urgent; mirrors the core's `attention_rank` (`crates/core/src/view.rs:140`) but reads the card, not a single state, so it can aggregate: `blocked` (0) if `c.state === "blocked"` **or any live session is blocked**, then `interrupted` (1), `needs decision` (2 — a card with a PR artifact whose `last_status` is `ci_passed | merged | closed | ci_failed`), `working` (4), `paused` (3), `idle` (5), `offline` (6), `empty` (7). Ties break by newer `updated_at`, then id, so the order is stable.
- Produces: `export function attentionSorted(cards: Card[]): Card[]`.

```ts

import type { Card, Session } from "../api";

const session = (s: Partial<Session>): Session => ({
  link_id: s.link_id ?? "l1", status: "idle", last_status: "idle", live: true,
  pane_id: "w1:p1", agent: "claude", title: null, station_id: null, station_name: null,
  prompt: null, pending_prompt: null, workspace: null, cwd: null,
  created_at: 1, last_seen: 1, output_at: null, ...s,
});
const card = (c: Partial<Card> & { id: string; state: Card["state"] }): Card => ({
  title: c.id, cwd: "/w", notes: "", done: false, created_at: 1, updated_at: 1,
  sessions: [], artifacts: [], kind: "repo", ...c,
});

describe("attention ordering", () => {
  it("puts blocked first even when the newest session is interrupted", () => {
    const c = card({
      id: "c1", state: "interrupted",
      sessions: [
        session({ link_id: "old", created_at: 1, status: "blocked" }),
        session({ link_id: "new", created_at: 2, live: false, status: "offline", end_reason: "interrupted" }),
      ],
    });
    expect(attentionRank(c)).toBe(0);
  });

  it("treats a finished PR as a decision, ahead of plain working", () => {
    const pr = card({ id: "pr", state: "working", artifacts: [{ id: "a", kind: "pr", label: "PR", target: "https://github.com/o/r/pull/1", last_status: "ci_passed", checked_at: 1 }] });
    const work = card({ id: "w", state: "working" });
    expect(attentionRank(pr)).toBeLessThan(attentionRank(work));
  });

  it("sorts stably and keeps done cards last", () => {
    const list = [card({ id: "a", state: "idle" }), card({ id: "b", state: "blocked" }), card({ id: "c", state: "interrupted" })];
    expect(attentionSorted(list).map((c) => c.id)).toEqual(["b", "c", "a"]);
    const tie = [card({ id: "x", state: "idle", updated_at: 1 }), card({ id: "y", state: "idle", updated_at: 2 })];
    expect(attentionSorted(tie).map((c) => c.id)).toEqual(["y", "x"]);
  });
});
```

```ts
addArtifact: async (cardId, kind, label, target) => {
  const c = card(cardId);
  const id = `a${seq++}`;
  c.artifacts.push({ id, kind, label, target, last_status: kind === "pr" ? "ci_running" : null, checked_at: Date.now() });
  notify();
  return id;

openArtifact: async (cardId, artifactId) => {
  const a = card(cardId).artifacts.find((x) => x.id === artifactId);
  if (!a) throw "that artifact no longer exists";
},
readLog: async (cardId, limit) => {
  card(cardId);
  const all = logs.get(cardId) ?? [];
  return limit ? all.slice(-limit) : all;
},
appendLog: async (cardId, text, opts) => {
  if (cardId.includes("..") || cardId.includes("/")) throw `not a usable card id: ${cardId}`;
  card(cardId);
  if (!text.trim()) throw "write something first";
  const e: LogEntry = { id: `e${seq++}`, owner: "captain", at: Date.now(), kind: opts?.kind ?? "note", text: text.trim(), links: [], session_id: opts?.sessionId ?? null };
  logs.set(cardId, [...(logs.get(cardId) ?? []), e]);
  notify();
  return e;
},
```

```tsx
export function CardConsole({ card }: { card: Card }) {
  const [entries, setEntries] = useState<LogEntry[] | null>(null);
  const [text, setText] = useState("");
  const [error, setError] = useState<string | null>(null);
  const [collapsed, setCollapsed] = useState<Record<string, boolean>>({});
  useEffect(() => {
    let alive = true;
    backend.readLog(card.id).then((e) => alive && setEntries(e), (e) => alive && setError(errorText(e)));
    return () => { alive = false; };
  }, [card.id]);
  const send = () => backend.appendLog(card.id, text)
    .then((e) => (setEntries((old) => [...(old ?? []), e]), setText(""), setError(null)))
    .catch((e) => setError(errorText(e)));
  if (!entries) return <div className="console">{error ?? "Loading log…"}</div>;
  const rounds = logByRound(entries);
  return (
    <div className="console">
      <h3>Captain's log</h3>
      {rounds.map((r, i) => (
        // Old rounds collapse by default (spec §11.1): the newest is open.
        <section key={r.round} className="round">
          <button className="ghost" onClick={() => setCollapsed((c) => ({ ...c, [r.round]: !(c[r.round] ?? i > 0) }))}>
            {r.round === "captain" ? "Bridge" : r.round} · {r.entries.length} entries
            {(collapsed[r.round] ?? i > 0) ? " ▸" : " ▾"}
          </button>
          {!(collapsed[r.round] ?? i > 0) && (
            <ol>
              {r.entries.map((e) => (
                <li key={e.id}>
                  <span className="muted">{timeAgo(e.at)} · {e.owner} · {e.kind}</span>
                  <p>{e.text}</p>
                </li>
              ))}
            </ol>
          )}
        </section>
      ))}
      <form className="followup" onSubmit={(ev) => (ev.preventDefault(), send())}>
        <textarea value={text} onChange={(ev) => setText(ev.target.value)} rows={2} placeholder="Write one line: where you left off" />
        <button type="submit" className="primary" disabled={!text.trim()}>Log</button>
      </form>
      <ErrorNote text={error} />
    </div>
  );
}
```
