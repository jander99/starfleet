# Stage 2A: PR poller, artifacts and logs in core — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make a card's PR artifact live and durable in the Rust core: `gh` preflight, a per-PR poller inside the monitor loop with backoff and a global concurrency cap, open actions, and the Captain's log IPC.

**Architecture:** A new pure-ish module `crates/core/src/github.rs` owns PR URL parsing, `gh` JSON → status mapping, the `gh` invocation through `HostEnv`, and a `PrPoller` scheduler keyed by PR URL. `app.rs` wires it into the existing `run_monitor` loop and exposes the four commands the UI calls (`add_artifact`, `open_artifact`, `read_log`, `append_log`), which `src-tauri/src/lib.rs` forwards. No UI behavior changes: this plan is the core half of MVP slice one.

**Tech Stack:** Rust 2021, tokio (rt-multi-thread, process, sync, time), serde/serde_json, anyhow, `gh` CLI via `HostEnv`, `mock-herdr` for the e2e test.

**Spec:** `docs/superpowers/specs/2026-11-17-starfleet-bridge-design.md` (§6 artifacts, §8.2 PR poller, §10 storage, §12 credentials)

## Global Constraints

- Workspace dependencies only — no new crates. tokio features available: rt-multi-thread, macros, net, io-util, process, sync, time.
- PR polling cadence: every 60s while CI is running, backing off when quiet or rate-limited (spec §8.2). Backoff cap 10 minutes.
- Polls are keyed by PR URL, never by card; two cards on one PR share one poll (spec §8.2).
- Global cap on concurrent `gh` calls: 2.
- `GITHUB_TOKEN` comes from the environment; it is never written to the board file or the logs (spec §12).
- `gh` runs through `HostEnv` exactly like every other probe, so WSL on Windows works the same way (`crates/core/src/env.rs`).
- Card ids become filenames — `crates/core/src/log.rs` already rejects `/`, `\` and `..`; do not bypass it.
- Status strings are exactly: `merged closed draft ci_failed ci_running ci_passed open unknown`.
- `cargo fmt --check` must pass; CI runs it.

## Review Focus

The five things most likely to bite a user, with the test that pins each one appearing in the owning task:

1. A PR artifact whose target is not a GitHub pull URL (an issue URL, a trailing slash, `.diff`) — parse returns `None`, the artifact keeps its previous status, nothing panics (Task 3).
2. `gh` unauthenticated or rate-limited — the artifact gets `unknown` with a fresh `checked_at`, backoff doubles, and the loop never spins tight (Tasks 4, 5).
3. Two cards pointing at the same PR — one `gh` call per interval, both artifacts updated (Task 6).
4. An artifact deleted from the board while its poll is in flight — `update_artifact`'s error is swallowed and polling continues (Task 6).
5. `append_log` on a card whose id contains `..` — rejected with an error, no file written outside the logs dir (Task 7).

```rust
#[derive(Clone, Debug, PartialEq)]
pub struct PrArtifact {
    pub card_id: String,

    pub target: String,

}
```

```rust
pub async fn fetch_pr(env: &HostEnv, gh: &str, url: &str) -> Result<PrStatus, GhError> {
    parse_pr_url(url).ok_or_else(|| GhError::Other(format!("not a GitHub pull url: {url}")))?;
    let script = format!(
        "{} pr view {} --json state,isDraft,statusCheckRollup",
        sh_quote(gh),
        sh_quote(url)
    );
    let out = env
        .sh(&script)
        .await
        .map_err(|e| GhError::Other(e.to_string()))?;
    if !out.ok {
        return Err(if out.stderr.to_lowercase().contains("rate limit") {
            GhError::RateLimited
        } else {
            GhError::Other(if out.stderr.is_empty() { out.stdout } else { out.stderr })
        });
    }
    let json: serde_json::Value =
        serde_json::from_str(&out.stdout).map_err(|e| GhError::Other(e.to_string()))?;
    Ok(status_from_gh(&json))
}
```

```rust
fn rate_limits_back_off_exponentially_up_to_the_cap() {
    let url = "https://github.com/o/r/pull/7".to_string();
    let mut p = PrPoller::new(1);
    let mut t = 0;
    for expected in [120_000, 240_000, 480_000, 600_000, 600_000] {
        p.due(&[url.clone()], t);
        p.record(&url, PollOutcome::RateLimited, t);
        t += expected;
        assert!(p.due(&[url.clone()], t - 1).is_empty(), "too early at {t}");
        assert_eq!(p.due(&[url.clone()], t), vec![url.clone()]);

    // Success resets the backoff.
    p.record(&url, PollOutcome::Ok, t);
    assert!(p.due(&[url.clone()], t + 59_999).is_empty());
    assert_eq!(p.due(&[url.clone()], t + 60_000).len(), 1);
}
```

```rust
/// Poll the due PR artifacts once: one gh call per distinct PR url, at most
/// the cap at a time. Returns how many PRs were polled.
pub async fn poll_prs_once(&self, now_ms: u64) -> usize {
    let prs = self.store.lock().unwrap().pr_artifacts();
    let mut urls: Vec<String> = Vec::new();
    for p in &prs {
        if !urls.contains(&p.target) {
            urls.push(p.target.clone());
        }
    }
    {
        let mut poller = self.pr.lock().unwrap();
        poller.retain(&urls);
    }
    let due = self.pr.lock().unwrap().due(&urls, now_ms);
    let mut results = Vec::new();
    for url in &due {
        let env = self.env.clone();
        let gh = self.gh.clone();
        let url = url.clone();
        let r = fetch_pr(&env, &gh, &url).await;
        results.push((url, r));
    }
    let mut polled = 0;
    for (url, r) in results {
        let (status, outcome) = match r {
            Ok(s) => (s.as_str(), PollOutcome::Ok),
            Err(GhError::RateLimited) => ("unknown", PollOutcome::RateLimited),
            Err(GhError::Other(_)) => ("unknown", PollOutcome::Failed),
        };
        let mut changed = false;
        {
            let mut store = self.store.lock().unwrap();
            for p in prs.iter().filter(|p| p.target == url) {
                // The artifact may be gone: the board was edited mid-poll.
                if store.update_artifact(&p.card_id, &p.artifact_id, Some(status), Some(now_ms())).is_ok() {
                    changed = true;
                }
            }
        }
        self.pr.lock().unwrap().record(&url, outcome, now_ms);
        if changed {
            self.notify();
        }
        polled += 1;
    }
    polled
}
```
